# 桌面适配

同一套判据，桌面有五个额外约束：**密度更高、窗口是边界、键盘是一等公民、主题跟随系统、chrome 要自己负责。**

## 1. 先定形态，再谈视觉

| 形态 | 用户来的目的 | 首屏应该是 | 不该出现 |
| --- | --- | --- | --- |
| 工具（转换器、清理器） | 一件事，做完就走 | 输入区 + 主按钮 + 结果区，同屏 | 欢迎页、功能介绍、页脚 |
| 工作台（IDE、下载器、编辑器） | 长时间停留、反复操作 | 三栏：导航 / 内容 / 属性或日志 | 居中大标题、大留白 |
| 仪表盘 | 扫一眼判断状态 | 关键指标 + 异常列表前置 | 轮播、装饰图表 |
| 文档/媒体 | 沉浸阅读或观看 | 内容本身满幅 | 工具栏挤占、双滚动条 |

判断方法：**用户打开这个窗口后的前 10 秒要做什么。** 那个东西必须在首屏、在默认焦点附近。

## 2. 窗口与 chrome

- **标题栏高度对齐系统**：Windows 32px、macOS 28px（红绿灯内缩 20/16）。自绘标题栏不要比系统更高，也不要放品牌名 + 副标题 + 版本号三行。
- **拖拽区**：无边框窗口必须显式标记。Electron `-webkit-app-region: drag`（按钮区 `no-drag`），Tauri `data-tauri-drag-region`，WPF 用 `WindowChrome` + `CaptionHeight`。
- **菜单**：桌面用户可以没有菜单，但不能**只有**汉堡菜单。至少保留右键菜单与快捷键。
- **状态栏**：一行，放连接状态、进度、计数。不要放宣传语。
- **关闭行为**：托盘、最小化到托盘、真退出要能分辨，且要有可撤销的提示。

## 3. 密度（桌面最容易被网页习惯毁掉的一项）

| 项 | Web | 桌面 |
| --- | --- | --- |
| 正文 | 15–16px | 13–14px |
| 行高 | 1.5–1.6 | 1.35–1.45 |
| 表格行高 | 44–56px | 28–32px |
| 内容边距 | 24–32px | 12–16px |
| 控件高度 | 40–44px | 28–32px |
| 分组间距 | 48–96px | 12–24px |
| 图标 | 20–24px | 14–16px |

窗口尺寸下，**1440 宽的落地页节奏（`py-24`、`text-6xl`）会立刻露馅**：内容稀、滚动长、看起来像套壳网页。

## 4. 字体与主题

- 字体优先系统栈：Windows `Segoe UI Variable Text`，macOS `SF Pro Text`，Linux `Noto Sans` / `Cantarell`，中文 `Microsoft YaHei UI` / `PingFang SC` / `Noto Sans CJK SC`。只在品牌强要求时引入 Web 字体，且要接受启动闪烁。
- 数字一律等宽对齐：CSS `font-variant-numeric: tabular-nums`；WPF `Typography.NumeralAlignment="Tabular"`；QML `font.features: {"tnum"}`。
- 主题 token 化：浅色/深色两套 key 集合必须完全一致，切换时只换字典，不改视图。

**WPF**：颜色走 `DynamicResource`（要热切换），尺寸走 `StaticResource`；默认控件的模板自带圆角、渐变、蓝色高亮，只改 `Background` 改不掉，必须重写 `ControlTemplate`。系统色用 `SystemColors`（高对比模式下自动正确）。

切主题前先比两套资源字典的键集合：浅色有、暗色没有的键，在暗色下会静默退回父级值，症状是"某些地方没跟着变"。键集合必须完全一致，值可以不同。

**Electron/Tauri**：`nativeTheme.shouldUseDarkColors` / Tauri `theme()` 驱动 `<html data-theme>`；不要硬编码 `#fff`。

**Qt/QML**：`SystemPalette` 或平台 style（Windows 用 Fusion + 自绘 token），不要在 `Rectangle` 里写字面颜色。

## 5. 键盘与交互（桌面用户的第一预期）

| 操作 | 必须支持 |
| --- | --- |
| Tab / Shift+Tab | 顺序合理，焦点环可见（2px，对比 ≥ 3:1） |
| Enter | 提交当前表单 / 打开选中项 |
| Esc | 关闭弹层、取消编辑、退出全屏 |
| 方向键 | 列表、表格、树内移动；不要被输入框吞掉 |
| Ctrl/Cmd+Z | 可撤销的操作要真能撤销 |
| Ctrl/Cmd+F | 长列表/日志/文档里可搜索 |
| 右键 | 复制、粘贴、在文件夹中显示等上下文动作 |
| 文本选择 | 任何非按钮文本都应可选中复制 |

## 6. 桌面专属的反 AI 味清单

出现即删：

- 首屏的 hero 区（大标题 + 副标题 + 两枚按钮）——桌面没有"落地"这回事。
- 页脚：版权、社交链接、备案号。桌面应用没有页脚。
- 三张功能卡片、客户 logo 墙、"为什么选择我们"。
- 玻璃拟态导航条、悬浮阴影卡片堆叠。
- 汉堡菜单里塞进三个一级入口。
- 整窗滚动 + 内容区里再套滚动。
- 无边框窗口却没做拖拽区（用户第一秒就发现拖不动）。

## 7. 验收

1. 最小 800×600 下布局不塌、不出现横向滚动。
2. 目标尺寸（如 1180×660）下首屏做完主任务不需要滚动。
3. 200% DPI 下图标不糊、文字不裁切。
4. 系统切暗色、切高对比后仍可读。
5. 全程只用键盘走一遍主流程。
6. 窗口在第二显示器上拖动，尺寸与位置能恢复（记住上次窗口状态）。
